# Logistics Data Analytics

## Week 1 Internship Project

This project presents a data-driven approach to logistics planning, KPI analysis,
delivery-risk prediction, customer/location clustering, and route/inventory
optimization.

### Objectives
- Measure logistics performance using KPIs.
- Clean and explore logistics data.
- Analyse delivery delays and inventory behaviour.
- Build a baseline machine-learning workflow.
- Propose route and inventory optimization strategies.

### KPIs
1. On-Time Delivery Rate
2. Average Delivery Time
3. Inventory Turnover
4. Transportation Cost per Delivery

### Tools
Python, pandas, NumPy, scikit-learn and matplotlib.

### Project structure
- `Week_1_Logistics_Strategic_Planning_Report.docx` - internship report
- `logistics_analysis.py` - starter Python analysis script
- `requirements.txt` - Python dependencies

### Dataset
The report identifies public supply-chain datasets that may be used for
educational analysis. Dataset licensing and usage conditions should be checked
before downloading or redistributing any dataset.
